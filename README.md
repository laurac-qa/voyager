# Voyager

> A modern travel planner built to demonstrate professional QA Engineering practices.

Voyager is a portfolio project that follows a real Agile development workflow. The application is being built incrementally while showcasing modern frontend development, test automation, API testing, SQL validation, CI/CD, and project management.
